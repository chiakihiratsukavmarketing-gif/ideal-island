# MILE

## 概要

MILEは、年間目標から今月の目標を決め、今月の目標から今日やることへ落とし込む逆算型目標管理アプリです。

今日のタスク、期限、カテゴリ、進捗、達成履歴、振り返りメモを1つの画面で管理しながら、日々の行動と目標までの進み具合を見える化できます。

## 公開URL

https://ideal-island.vercel.app/

## 現在の位置づけ

MILEは、以下の流れを中心にした目標管理アプリです。

```text
年間目標 → 今月の目標 → 今日やること
```

タスク単体を管理するだけでなく、今日の行動が今月の目標や年間目標にどうつながっているかを確認できる状態になっています。

## データ保存仕様

データはブラウザの `localStorage` に保存しています。

保存対象:

- タスク一覧
- 期限
- カテゴリ
- 完了状態
- `completedAt`
- `monthlyGoalId`
- スローガン
- 振り返りメモ
- 年間目標
- 今月の目標

### mileGoalPlan

逆算型目標管理用のデータは `mileGoalPlan` に保存します。

```js
const mileGoalPlan = {
  yearlyGoal: {
    id: "year-2026",
    title: "",
    memo: "",
    createdAt: "",
    updatedAt: ""
  },
  monthlyGoals: [
    {
      id: "month-2026-06-xxxx",
      yearGoalId: "year-2026",
      title: "",
      month: "2026-06",
      category: "仕事",
      memo: "",
      createdAt: "",
      updatedAt: ""
    }
  ],
  dailyTasks: []
};
```

現在は、既存タスク側に `monthlyGoalId` を持たせて、今日のタスクと今月目標を紐づけています。`dailyTasks` は将来の構造整理用として残しています。

### 互換性

古い保存データでも読み込めるように補完処理があります。

- `dueDate` がない場合は空文字
- `category` がない場合は「その他」
- `completedAt` がない場合は空文字
- `monthlyGoalId` がない場合は空文字
- `mileGoalPlan` がない場合は初期化
