# MILE

## 概要

MILEは、今日やることを整理し、目標までの進捗を見える化するシンプルな目標管理アプリです。
タスク、期限、カテゴリ、進捗、達成履歴、振り返りメモを1つの画面で管理できます。

## データ保存仕様

MILEは現在、ブラウザの `localStorage` にデータを保存しています。

保存対象:

- タスク一覧
- 期限
- カテゴリ
- 完了状態
- `completedAt`
- スローガン
- 振り返りメモ

データ移行対応:

- 古いタスク形式でも読み込めるように補完処理あり
- `dueDate` がない場合は空文字として扱う
- `category` がない場合は「その他」として扱う
- `completedAt` がない場合は空文字として扱う
- 旧スローガンが残っている場合は新しい既定文言へ移行
